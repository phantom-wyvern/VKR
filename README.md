# Информационная система управления библиотечным фондом

Данный репозиторий содержит выпускную квалификационную работу (ВКР), посвященную проектированию, разработке и внедрению реляционной базы данных и веб-интерфейса для автоматизации деятельности публичной библиотеки. 

Система заменяет ручной бумажный учет, обеспечивая целостность данных, разграничение прав доступа и высокую скорость обработки транзакций.

## Основные возможности

### Для читателей:
* Просмотр каталога книг с фильтрацией по авторам, жанрам и годам издания.
* Бронирование литературы и отслеживание статуса брони.
* Личный кабинет с историей выдач и текущими задолженностями.
* Саморегистрация в системе.

### Для библиотекарей:
* Оформление выдачи и возврата книг (в т.ч. с автоматическим расчетом просрочки).
* Управление физическим фондом (добавление экземпляров, изменение статусов).
* Обработка бронирований (подтверждение, отмена).
* Формирование аналитических отчетов (рейтинг популярных книг, статистика выдач, просроченные задолженности).

### Для администраторов:
* Управление ролевой моделью и настройками системы (сроки выдачи, лимиты).
* Просмотр журнала аудита (автоматическое логирование всех изменений библиографических записей).

### Архитектурные и системные особенности:
* **Трехуровневая архитектура:** Клиент (Vue.js) -> API (FastAPI) -> СУБД (PostgreSQL).
* **Безопасность:** Трехуровневая ролевая модель на стороне СУБД (`lib_reader`, `lib_librarian`, `lib_admin`), хеширование паролей (bcrypt), защита от SQL-инъекций через ORM.
* **Целостность данных:** Нормализация до 3НФ, строгие CHECK- и UNIQUE-ограничения, каскадное удаление.
* **Аудит:** Триггерный механизм (`trg_book_audit`), фиксирующий все операции INSERT/UPDATE/DELETE в формате JSONB.
* **Оптимизация:** Частичные индексы (например, `idx_loan_active_copy` для предотвращения двойной выдачи одного экземпляра).

## Технологический стек

| Компонент | Технологии |
| :--- | :--- |
| **База данных** | PostgreSQL 16, PL/pgSQL (триггеры, хранимые функции) |
| **Backend** | Python 3.12+, FastAPI, SQLAlchemy 2.0 (async), asyncpg, Pydantic |
| **Frontend** | Vue.js 3, Vite, Pinia, PrimeVue, Vue Router |
| **Инфраструктура** | Docker, Docker Compose |
| **Тестирование** | pytest, FastAPI TestClient, pgAdmin, psql |

```text
